# 🚀 Практические задания по ООП на C# (Наследование и Полиморфизм)

Репозиторий содержит комплексное решение **30 учебных задач по объектно-ориентированному программированию** на языке C# (.NET 8.0).  
Проект спроектирован с упором на чистую архитектуру, соблюдение принципов SOLID, корректное использование механизмов наследования, полиморфизма, абстрактных классов и обобщенных коллекций.

## 📋 Каталог выполненных заданий

### Часть 1. Базовые принципы наследования и полиморфизма (Задания 1–20)

1. **`Task01_Animal` — Животное**
   - Базовый класс `Animal` с виртуальным методом `Speak()`.
   - Дочерние классы `Dog` («Гав-гав!») и `Cat` («Мяу-мяу!») с переопределением (`override`).
   - Демонстрация полиморфизма через коллекцию `List<Animal>`.

2. **`Task02_Vehicle` — Транспорт**
   - Базовый класс `Vehicle` со свойствами `Brand` и `Speed`.
   - `Car` с уникальным свойством `NumberOfDoors` (количество дверей).
   - `Motorcycle` со свойством `HasSidecar` (наличие коляски/люльки).

3. **`Task03_PersonStudent` — Человек и студент**
   - Базовый класс `Person` с полями имени и возраста.
   - Производный класс `Student`, расширенный свойствами `Specialty` (специальность), `Course` (курс) и методом `Study()`.

4. **`Task04_Employees` — Сотрудники**
   - Базовый класс `Employee` (`Name`, `Salary`).
   - `Manager` с дополнительным полем `TeamSize` (размер команды) и методом проведения планерок.
   - `Developer` с полем `PrimaryLanguage` (язык программирования) и методом `WriteCode()`.

5. **`Task05_Shapes` — Фигуры**
   - Базовый класс `Shape` с виртуальным методом `GetArea()`.
   - `Rectangle` (вычисление площади по ширине и высоте) и `Circle` (вычисление через радиус и $\pi$).

6. **`Task06_VehicleMovement` — Транспорт с методом движения**
   - Базовый класс `Vehicle` с методом `Move()`.
   - `Car`, `Bus`, `Train` реализуют собственное уникальное поведение движения (автомагистраль, городские остановки, рельсы).

7. **`Task07_StoreWorker` — Работник магазина**
   - Базовый класс `Worker` с именем и должностью.
   - `Cashier` (номер кассы, пробитие чека покупателю).
   - `Seller` (отдел продаж, консультация и оформление покупки).

8. **`Task08_Computers` — Компьютеры**
   - Базовый класс `Computer` с процессором (`Processor`) и объемом ОЗУ (`RamGb`).
   - `Laptop` (емкость аккумулятора, масса устройства).
   - `Desktop` (форм-фактор системного блока, мощность блока питания).

9. **`Task09_Books` — Книги**
   - Базовый класс `Book` (`Title`, `Author`).
   - `PaperBook` (количество страниц, тип обложки).
   - `EBook` (размер файла в МБ, цифровой формат FB2/EPUB/PDF, скачивание).

10. **`Task10_Pets` — Домашние животные**
    - Базовый класс `Pet` с методом `Eat()`.
    - `Dog`, `Cat`, `Parrot` с индивидуальным рационом питания и поведением при кормлении.

11. **`Task11_BankAccounts` — Банковские счета**
    - Базовый класс `BankAccount` с балансом и методами `Deposit()` и `Withdraw()`.
    - `SavingsAccount` с начислением процентов (`ApplyInterest()`) и защитой неснижаемого остатка.
    - `CreditAccount` с кредитным лимитом и поддержкой овердрафта.

12. **`Task12_TransportCompany` — Транспортная компания**
    - Базовый класс `Transport` с виртуальным методом `CalculateCost(distance)`.
    - `Car` (легковой трансфер), `Truck` (расчет по тоннажу груза), `Bus` (пассажирские групповые перевозки).

13. **`Task13_CompanyWorkers` — Работники компании**
    - Базовый класс `Employee` с методом `GetSalary()`.
    - Уникальные формулы расчета:
      - `Programmer`: оклад + бонусы за закрытые таски;
      - `Designer`: оклад + оплата утвержденных макетов;
      - `Manager`: оклад + процент от выручки проектов.

14. **`Task14_EducationSystem` — Система образования**
    - Многоуровневое наследование: `Person` $\rightarrow$ `Student` $\rightarrow$ `GraduateStudent`.
    - Аккумуляция свойств на каждом уровне (ФИО/возраст $\rightarrow$ ВУЗ/курс/GPA $\rightarrow$ тема диссертации/научный руководитель/публикации).

15. **`Task15_MilitaryEquipment` — Военная техника**
    - Базовый класс `MilitaryVehicle` с бронированием и методом `Attack()`.
    - `Tank` (выстрел танковым орудием), `Helicopter` (залп управляемых ракет), `ArmoredCar` (пулеметная очередь).

16. **`Task16_GameCharacters` — Игровые персонажи**
    - Класс `Character` (`Health`, `Damage`).
    - `Warrior` (блокирование урона броней), `Mage` (трата маны на заклинания огня), `Archer` (критические выстрелы).
    - Симуляция пошагового сражения.

17. **`Task17_ElectronicDevices` — Электронные устройства**
    - Базовый класс `Device` с управлением питанием (`TurnOn()`, `TurnOff()`).
    - `Phone` (звонки, заряд батареи), `Computer` (запуск ОС и программ), `Television` (переключение каналов).

18. **`Task18_Payments` — Платежи**
    - Базовый класс `Payment` с генерацией номера транзакции и датой.
    - `CashPayment` (проверка внесенных купюр, сдача), `CardPayment` (маскирование карты, эквайринг), `OnlinePayment` (СБП, электронный чек).

19. **`Task19_BonusEmployees` — Сотрудники с бонусами**
    - `Employee` с зарплатой и расчетом бонуса.
    - Дифференцированные процентные ставки и премии для `Manager`, `Developer`, `SalesManager`.

20. **`Task20_ZooAnimals` — Животные зоопарка**
    - Базовый класс `Animal` с методами `Eat()` и `MakeSound()`.
    - 5 видов животных: `Lion`, `Elephant`, `Monkey`, `Penguin`, `Wolf` с реалистичной озвучкой и рационом.

### Часть 2. Повышенный уровень и Итоговая система (Задания 21–30)

21. **`Task21_AbstractShapes` — Абстрактные фигуры**
    - Абстрактный класс `Shape` с методами `abstract double GetArea()` и `abstract double GetPerimeter()`.
    - Реализации: `Circle`, `Rectangle`, `Triangle` (формула Герона с валидацией неравенства треугольника), `Square`.

22. **`Task22_OnlineStore` — Интернет-магазин**
    - Базовый класс `Product` и полиморфный расчет итоговой цены:
      - `Electronics`: учет сервисного гарантийного сбора и эко-налога;
      - `Clothing`: учет сезонной распродажи и акций;
      - `Food`: динамическая скидка 40% на товары с истекающим сроком годности.

23. **`Task23_TransportSystem` — Система транспорта**
    - Абстрактный класс `Transport` с методами `abstract void Move()` и `abstract double GetFuelConsumption(double distanceKm)`.
    - `Car`, `Truck` (динамический расход от массы груза), `Bus` (расход от заполненности салона), `Motorcycle`.

24. **`Task24_Hospital` — Больница**
    - Иерархия медперсонала: базовый `MedicalWorker` с виртуальным методом `Work()`.
    - `Doctor` (постановка диагнозов, назначение рецептов), `Nurse` (процедуры, контроль давления), `Surgeon` (проведение операций).

25. **`Task25_EmployeeHierarchy` — Система сотрудников с уровнями наследования**
    - Цепочка наследования из 4 уровней: `Person` $\rightarrow$ `Employee` $\rightarrow$ `Manager` $\rightarrow$ `Director`.
    - На **каждом** уровне строго добавлены минимум 2 свойства и 1 метод.
    - Полная демонстрация доступа верхнего уровня ко всей иерархии предков.

26. **`Task26_RPGCharacters` — Игра: персонажи**
    - Абстрактный класс `Character` с абстрактными методами: `Attack()`, `Defend()`, `SpecialAttack()`.
    - Классы `Warrior` (ультимейт «Вихрь клинков»), `Mage` («Метеоритный дождь»), `Archer` («Град стрел»).

27. **`Task27_FileSystem` — Файлы**
    - Базовый класс `File` (`FileName`, `SizeKb`).
    - `TextFile` (кодировка, число строк, открытие в текстовом редакторе).
    - `ImageFile` (разрешение WxH, цветовой профиль, рендеринг изображения).
    - `VideoFile` (длительность, видеокодек, воспроизведение медиаплеером).

28. **`Task28_PayrollSystem` — Система оплаты зарплаты**
    - Абстрактный класс `Employee` с методом `abstract decimal CalculateSalary()`.
    - `HourlyEmployee` (почасовая оплата со сверхурочным коэффициентом x1.5 при работе свыше 160 ч).
    - `SalariedEmployee` (фиксированный оклад + премия за KPI).
    - `CommissionEmployee` (базовый оклад + процент от валовых продаж).
    - Расчет сводного фонда оплаты труда (ФОТ) компании по коллекции сотрудников.

29. **`Task29_AnimalPolymorphism` — Полиморфизм + наследование**
    - Базовый класс `Animal` и 5 классов-потомков: `Dog`, `Cat`, `Cow`, `Sheep`, `Horse`.
    - Все объекты помещены в обобщенную коллекцию `List<Animal>`.
    - Демонстрация классического позднего связывания: вызов `MakeSound()` для всех животных в **одном цикле `foreach`**.

30. **`Task30_FleetSystem` — Итоговое задание: комплексная система автопарка**
    - Базовый абстрактный класс `Vehicle` (Id, Brand, Model, Year, Price, MaxSpeed, FuelConsumptionPer100Km).
    - 5 специализированных видов транспорта:
      - `Car` (объем багажника, пассажирские места);
      - `Truck` (грузоподъемность в тоннах, количество осей);
      - `Bus` (пассажировместимость, аппарель для маломобильных граждан);
      - `ElectricCar` (емкость батареи в кВт·ч, запас хода, расчет энергопотребления);
      - `Motorcycle` (объем двигателя в см³, наличие коляски).
    - Класс `FleetManager` для централизованного управления:
      - Коллекция `List<Vehicle>`;
      - Добавление и безопасное списание транспорта по ID;
      - Форматированный табличный вывод информации об автопарке;
      - Расчет совокупного расхода топлива и электроэнергии для любого заданного маршрута;
      - Быстрый поиск самого скоростного (`FindFastestVehicle`) и самого дорогостоящего (`FindMostExpensiveVehicle`) транспорта.

## 🛠 Сборка и запуск проектов

### Требования
* [.NET SDK 8.0](https://dotnet.microsoft.com/download) или выше.
* Любая среда разработки: Visual Studio 2022, JetBrains Rider или Visual Studio Code (с расширением C# Dev Kit).

### Запуск через консоль (.NET CLI)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/<your-username>/InheritanceTasks.git
   cd InheritanceTasks
   ```

2. Запустите любое нужное задание напрямую:
   ```bash
   # Запуск задания №1
   dotnet run --project Task01_Animal

   # Запуск задания №25
   dotnet run --project Task25_EmployeeHierarchy

   # Запуск итоговой системы автопарка (№30)
   dotnet run --project Task30_FleetSystem
   ```

### Запуск через Visual Studio / Rider
* Откройте файл `InheritanceTasks.sln`.
* В обозревателе решений (Solution Explorer) кликните правой кнопкой мыши по нужному заданию $\rightarrow$ **Set as Startup Project** («Назначить запускаемым проектом»).
* Нажмите `F5` или кнопку **Start**.

## 🌟 Примененные принципы ООП

- **Инкапсуляция**: Все поля скрыты за свойствами с геттерами/сеттерами, валидацией аргументов и защищенными модификаторами доступа (`protected set`).
- **Наследование**: Логичное выделение общих признаков в базовые классы и повторное использование кода с вызовами базовых конструкторов через `base(...)`.
- **Полиморфизм**: Использование ключевых слов `virtual`, `override` и `abstract` для динамической диспетчеризации методов во время выполнения программы.
- **Абстракция**: Изоляция контрактов в абстрактных классах для предотвращения создания неполноценных объектов базовых сущностей.
- **Типобезопасные коллекции**: Применение обобщенных коллекций `List<T>` и LINQ-запросов для фильтрации, поиска и агрегации данных.
